串口未出现或连接失败？

串口列表只显示板上 CH340K（WCH）或乐鑫原生 USB，Mac 的 Bluetooth-Incoming-Port 不是开发板。若列表为空，请检查板子是否通电、换一根能传数据的 USB 线，直接插电脑 USB 口，并关闭占用串口的终端与其他烧录页。若能选到 USB JTAG/serial debug unit，但自动连接仍显示同步失败：按住板上的用户/BOOT 键，点一下 RESET，松开用户/BOOT 键，再将上方连接方式改为“设备已手动进入下载模式”并重试。原厂文档说明 UART0 的 CH340K 支持自动下载；也可参考立创板卡说明。
